## 五、技术要点复盘（防再犯）

1. **AssetRipper 3.4 判死**：症状 = LoadFolder 成功但 Export 秒完成只出 EditorSettings；先查 `ExportUnreadableAssets` 开关（true=生肉全出），再版本伪造（等长替换，仅喂工具不改原件）。
2. **AssetRipper 无 CLI**：`--headless --port N` + `/openapi.json`，POST form `path=...`。
3. **UnityPy 3.x 网格**：Vector3f 对象列表、`firstByte/indexCount` 无 m_ 前缀、独立 `m_IndexBuffer`（ushort）、OBJ 用 `(-x, y, z)`。
4. **TypeTreeGenerator**：按依赖顺序 load_dll（mscorlib→UnityEngine→…）；JS 程序集必挂，需手工建树。
5. **Unity 3.4.2 安装**：NSIS 但 `/D=` 被无视 → 默认 `C:\Program Files (x86)\Unity\Editor`；`batchmode` 无证卡死 90s+（许可证未激活实锤）。
